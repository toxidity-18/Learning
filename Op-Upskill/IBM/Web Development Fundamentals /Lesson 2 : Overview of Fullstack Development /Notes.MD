# About this . 
- Full stack developer : they work both the frontend and backend , they ensure that the entire website or web application function seamlessly from the user interface to the server-side logic.
- Fullstack Development : is the end to end development and design of website and applications .
- Front to back END .
- Comparison of a grocery store to fullstack development . 

## Full stack Development . 
1. Front End Development . 

    - This is the part in which the user directly interacts with eg button menus displays card picture checkout etc . 
    
2. Back End Development .

    - The warehouse behind the grocery store is its back end . Here the store manager will handle processes like eg : inventory management , restocking products , handle transactions and manage supply chains .
    - Behind the scene processes include quality check and security management . 
    - Back - End involves server side programming and database management . THe fullstack Dev must be able to implement back-end functionality data processing and business logic for the applications .
    - They are responsible for storing managing and retrieving data for the web application .

3 . Server and infrastructure . 

   - In a grocery store physical infrastructure are very critical for store operations : eg shelves , refrigerator unit , cash register push art and other physical assets . 
   - IN web application the server and infrastructure work behind the scene to ensure smooth operations . 
   - A full stack developer has to understand the software and hardware components thus ensuring optimal performance .
   - This hardware and software components might include web server , cloud services , database , server management , hosting platforms nad deployment services 

## Summary : 
- Grocery store require coordination between the front and back end with the operational side thus ensuring seamless shopping experience for the customers .
- Web application require the front - back - server - infrastructure to work together in order to create and deliver a fully functional web application .
