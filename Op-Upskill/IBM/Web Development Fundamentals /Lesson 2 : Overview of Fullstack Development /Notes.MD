2. Back End Development .

    - The warehouse behind the grocery store is its back end . Here the store manager will handle processes like eg : inventory management , restocking products , handle transactions and manage supply chains .

3 . Server and infrastructure .

- Web application require the front - back - server - infrastructure to work together in order to create and deliver a fully functional web application .

## Tech used in full stack Development .
- 3 Layers of full stack development i.e front back and server and infrastructure ... 

1. Layer 1 : Front end . User interface . 

    - This is the layer that the user interacts with , they use HTML (Hypertext markup language) for page structure and content , CSS (Cascading style sheets) for styling , and JavaScript for dynamic behavior .
    - It is responsible for the user interface and user experience of the web application .
    - And complex frameworks like ( react angular and vue js)

2. Layer 2 : Back end . Server side logic .

    - This layer handle server side logic and data storage . . .
    - Dev will use server side programming language eg python ruby java etc to handle the application/ server logic . . . 
    - Runtime environment : (Node.js) - Javascript use this runtime environment to handle user request and response on the server side .
    - Javascript has it's own framework for server side development which is express.js 
    - To model store and manage data we require database such as MongoDB , MYSQL , POSTGRESQL etc . . .
    - The server side logic / application logic will communicate with the database logic through the use of APIS ( Application programming Interface) . Common architecture of APIs are REST , SOAP and GRAPHQL

3 . Layer 3 : Server and infrastructure .

- This layer will manage the server , cloud services and deployment of the application . . .
- Platform which are used to manage the server and deploy the application include docker and kubernetes .
- Cloud platform such as IBM cloud , AWS ( Amazon web service ) , azure and google cloud provide the infrastructure for the application .

## Essential components of fullstack development . . .

- This components enable you to build a complete web application from scratch . 

1. Front end development .
* Create visually appealing and user friendly UI through the use of html css and javascript . . .
* Client side programming through use of javascript thus handling user interaction , validate form and manage dynamic content through DOM document object model .
* Libraries and frameworks eg React Angular and vue js . to streamline front - end development and build interactive web applications . 
* Create responsive designs  to ensure that the web application is accessible and functional . . .

2. Back end development . 
* Data processing , business logic and server side routing are all handle by the server side logic through the use of runtime environment eg Node.js and use of server side programming languages such as python and ruby 
* Working with database include design schema , store and retrieve data and writing database queries .
* Application programming interface allows communication between the front end and back end components .
* Web application require to be secure thus they need user access authorization and authentication .

3. DevOps and Workflows . 
* Development workflow and processes will be used by developer , tester and deployment team .
* Git is used to automate task .
* Adopt devOp practices for efficient development and testing and deployment . 

4. Version control .
* Examples of version control system include git and mercurial .
