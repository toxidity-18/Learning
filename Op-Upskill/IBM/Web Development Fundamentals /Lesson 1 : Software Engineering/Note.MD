## Key principles of software engineering .
1. Systematic approach .( systematic and disciplined approach to software development )
  
  - It involves phases which include : requirements gathering , software design , development , testing , deployment and maintenance .
  - This usually help in collaboration  and completing the assigned task withing the timeline and budget . 

2. Quality assurance .
  - Quality assurance testing inspection and process monitoring to identify defects and discrepancies in the software 
  -  Predefined standards and quality bench marks .

3. Abstraction .
  - Is the process of hiding complex code and redundant details and show only the relevant information to the user .
  - Simplify complex systems by breaking them down into smaller modules thus making them more maintainable and manageable .
  - This enhances code readability and make it easier to use and maintain .. 

4. Documentation , 
  - Through out the project lifecycle make sure to maintain a comprehensive documentation . 
  - Document user requirements , architectural diagrams , design details changes bugs and fixes tets record user feedback and user manuals . 
  - This helps understand and maintain and scale the software that you are developing .

5. Reusability . 
  - Develop modular code components that can be reused wherever possible . Use the reusable components and libraries instead of writing code from scratch . 
  - Reduces redundancies , accelerate development and enhance maintainability .

6. Iterative Development . 
  - Allows flexibility , adapts to changing requirements and support  continuous developments .
  - This will help you develop the software in small increment and handle change detect and fix defects . 

## Primary Aspects of software engineering . 
  - Holistic approach which considers the following aspects of software development life cycle . 
  - SDLC Framework for systematically building high quality software and website which meet user requirements . 
  - Provides a way to plan large project . 

1. Requirements Engineering  : process of gathering analyzing and documenting both the client and user needs and expectations . This input helps you define the software functionality and constraint . 
2. Software architecture and design : S A : Hide the implementation details but it define the overall structure for the software systems . 
   - Usually includes identifying the software components and modules and how they will be developed and how they will work together . 
   - Software Design acts like a blueprint which define the implementation details for each component and their functionalities . 

3. Coding : Process for writing the actual code for the software program . 
  - Implement the functionality that is defined in the design phase . 

4. Software maintenance : this is an ongoing activity which involves supporting and enhancing the software , this can be done through providing updates , fix bugs and optimize application performance .
  - It is an activity that is regularly conducted after deployment thus keeping the software usable and efficient ,

5. Software Testing and validation . 
  : - This is part of the quality assurance process for creating the software .
  - S Testing : detect and fiz defects . 
  - S Validation : evaluating the software against user requirements to ensure that it meets user need and expectations .

6. Software Deployment .
  : - Means making the software available to users . Install configure and set up the server .

7. Security Engineering .
  - This is the process of building with security in mind to ensure safety of user data and minimize the risk of attack . 

8. User Interface and User Experience .
  - Aspects of software engineering whose main focus is to ensure that the software is functional easy and pleasing to use .
  - UI user friendly and visual appealing .
  - UX create user centered design which are enjoyable and efficient .
