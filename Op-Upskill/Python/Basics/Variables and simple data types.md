## Variables 

### Naming and using variable . 
* Using variable in python demand that you adhere to a few rule and guideline , breaking any of them will lead to errors .
* This rules and guidelines help make your code simple readable and understandable .

  1. Variable names of contain letter number and underscore  , and they should never start with a number .  Eg message_1 , _message . NB NOT 1_message .
  2. Spaces are not allowed in variable names but underscores can be used to separate them . 
  3. Python keywords and function names should not be used as variable names . I.E Words which python has reserved for programmatic purposes .
  4. Variable names should be short but descriptive , e.g name is bette than n , student_name is better than s_n .

* Python variable names ought to be lower case and not upper case at this point . 

### Avoiding name errors when using variable.
* As a programmer try as much as possible to respond to error efficiently and effectively . 
* Name error : we either forgot to set the variable value or we made the spelling mistake when writing the variable name .
